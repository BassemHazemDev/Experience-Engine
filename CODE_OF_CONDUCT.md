# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its full text applies to all project spaces: issues, pull requests, discussions and any other place where the project is represented.

## In short

We want participation in this project to be free of harassment for everyone, whatever their age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

Expected:

- Be respectful of differing viewpoints and experience.
- Give and accept constructive feedback gracefully.
- Take responsibility for mistakes and learn from them.
- Focus on what is best for the people using and building the project.

Not acceptable:

- Sexualized language or imagery, and unwelcome sexual attention or advances.
- Trolling, insults, and personal or political attacks.
- Public or private harassment.
- Publishing someone else's private information without permission.

## Reporting

Report unacceptable behaviour to the maintainer privately, through the contact options on the maintainer's GitHub profile, or by using **Security → Report a vulnerability** on the repository, which opens a private channel. Reports are reviewed promptly and kept confidential.

## Enforcement

The maintainer may remove, edit or reject comments, commits, issues and other contributions that do not follow this code of conduct, and may ban contributors temporarily or permanently, following the enforcement guidelines of the Contributor Covenant.
