## 4. Double-blind check before submission

Confirm:
- no author names in the PDF title/header
- no institution names in the title/header
- no identifying acknowledgements
- no author metadata in the anonymous PDF
- self-citations follow the venue's anonymization rule
- no accidental identifying file names are uploaded for the review manuscript

## 5. Research-claim check

The manuscript intentionally does NOT claim:
- first adaptive UI framework
- first multi-dimensional adaptation framework
- unique atomicity/stale-safety guarantees
- universal performance superiority
- universal deployment/cache behavior

It DOES claim the narrower ETP protocol abstraction and reports scoped empirical evidence, including React 18 E2E, Next.js RSC/client runtime validation, and request-time cookie personalization on a production Next.js setup.

## 6. Final submit gate

Before clicking Submit:
- verify active round/deadline in PCS
- verify every author
- verify conflicts
- verify abstract/keywords
- verify uploaded PDF opens correctly
- verify source upload is accepted if provided
- review all declarations
- save the PCS submission ID

## 7. After submission

Record:
- PCS submission ID
- submission round
- timestamp
- uploaded PDF SHA-256
- uploaded source SHA-256, if source was uploaded
- confirmation email/screenshot
